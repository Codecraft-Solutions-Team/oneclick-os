summary: PCs with an Nvidia graphics card use the Nvidia version of OneClick OS, which has the driver built in.

OneClick OS comes in two versions for PCs. One is for PCs with AMD or Intel graphics. The other is for PCs with **Nvidia** graphics. The Nvidia version has Nvidia's driver built in, so there is nothing to download or install afterwards.

## Which one do I have

You chose a version when you downloaded the installer. If you are not sure whether your PC has Nvidia graphics, or which version to pick, see [Which version for Nvidia graphics](/getting-started/nvidia-version).

To see what graphics your PC has, open **About This PC** from the Start menu. The graphics card is listed with the other hardware. See [About This PC](/settings/about-this-pc).

## You do not install the driver yourself

On Windows you download drivers from Nvidia's website and use the GeForce Experience or Nvidia app. Neither is used here.

- The driver is part of the system.
- It is updated together with the system, when you choose to update. See [How updates work](/updates/how-updates-work).
- Nvidia's Windows installers do not work on OneClick OS. Do not download them.

If an update brings a driver that causes trouble, you can go back to the version you had before. See [Undo an update](/updates/undo-an-update).

## What is different from Windows

- There is no GeForce Experience or Nvidia app. Features that live in those apps, such as their game recording and automatic game settings, are not available.
- The **GeForce NOW** shortcut in the Start menu is a separate thing. It is a streaming service that works on any PC, with or without an Nvidia card. See [GeForce NOW](/gaming/geforce-now).
- Very old Nvidia cards may not be covered by the current driver. See [Will it run on my PC](/getting-started/is-my-pc-supported).

## Laptops with two graphics chips

Many gaming laptops have a low-power chip for everyday use and an Nvidia chip for games. Use the Nvidia version of OneClick OS on these laptops. Keep the laptop plugged in when you play.

## If the wrong version is installed

Signs of this are a low screen resolution that cannot be changed, a black screen after starting, or games running very poorly. See [Black screen after starting](/troubleshooting/black-screen) and [The screen is the wrong size or blurry](/troubleshooting/screen-wrong-size).

> Note: OneClick OS is an early test version. The Nvidia version is built automatically but has not been tested on many different Nvidia cards. If something is wrong, please [report a problem](/troubleshooting/report-a-problem) and include the model of your graphics card.
