The Epic Games Launcher and GOG Galaxy are Windows programs and are not available for OneClick OS. You can still play many of the games you own there, using a free launcher from the App Store.

## Which launcher for which store

| Store | Use |
| --- | --- |
| Steam | Steam. See [Set up Steam](/gaming/steam) |
| Epic Games Store | Heroic Games Launcher |
| GOG | Heroic Games Launcher |
| Amazon Games | Heroic Games Launcher |
| EA, Ubisoft, Battle.net and others | Lutris |
| Xbox and PC Game Pass | Streaming only. See [Xbox Cloud Gaming](/gaming/xbox-cloud-gaming) |

Heroic and Lutris are made by independent teams. They are not made by the stores, and they are not made by OneClick OS.

## Set up Heroic Games Launcher

1. Open the **App Store** from the Start menu.
2. Search for **Heroic Games Launcher** and press **Install**.
3. Open Heroic from the Start menu.
4. Sign in to your Epic, GOG or Amazon account inside Heroic. The sign-in page comes from the store itself.
5. Your library appears. Choose a game and install it.

Heroic runs Windows games in a similar way to Steam, and downloads what it needs the first time.

Heroic and Lutris are both in the Gamer starter set in the welcome tour. See [Choose your starter apps](/getting-started/choose-starter-apps).

## Lutris

Lutris is a launcher for games from many places, including stores that Heroic does not cover. It takes more setting up than Heroic. Install it from the App Store in the same way. Use it when Heroic does not support the store you need.

## What to expect

Games from these stores are less predictable than Steam games.

- Games that run well on Steam usually run from Epic or GOG as well.
- GOG games have no copy protection and tend to be the least trouble.
- Games that need a second launcher inside the first, such as some EA and Ubisoft games, fail more often.
- **Fortnite does not run.** Its anti-cheat only allows Windows. The same is true of some other online games. See [Why some online games will not run](/gaming/anti-cheat).

OneClick OS cannot promise that a particular game works. To judge a game's chances, look it up as described in [Check a game before you buy it](/gaming/check-a-game).

> Note: Do not use Bottles for games from these stores. The launchers above are built for games and handle them better.
