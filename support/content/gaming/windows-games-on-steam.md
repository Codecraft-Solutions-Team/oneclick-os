Most PC games are made for Windows. Steam includes a compatibility feature called **Proton** that lets many of them run on systems like OneClick OS. It is made by Valve, the company behind Steam, and it is part of Steam. There is nothing separate to install.

## How to use it

For most games you do nothing special.

1. Open **Steam** and go to **Library**.
2. Choose the game and press **Install**.
3. Press **Play**.

The first start of a game can take longer than usual while Steam prepares it. Later starts are quicker.

## If a game has no Install button, or will not start

Steam can be told to use its compatibility feature for a particular game.

1. In your Steam library, right-click the game and choose **Properties**.
2. Choose **Compatibility**.
3. Tick the option to force a specific Steam Play compatibility tool.
4. Pick a Proton version from the list. Try the newest numbered version first.

There is also a general setting. In Steam, open **Settings**, choose **Compatibility**, and make sure Steam Play is turned on for all titles.

> Note: Steam changes its menus from time to time. If the wording is a little different, look for the words "Compatibility" and "Steam Play".

## What to expect

- Many games run well with no changes.
- Some run with small problems, such as a video that does not play or a launcher that needs a second try.
- Some do not run at all. The most common reason is anti-cheat in online games. See [Why some online games will not run](/gaming/anti-cheat).

OneClick OS cannot promise that a particular game works. Other players report their results on [protondb.com](https://protondb.com), which is the best place to look. See [Check a game before you buy it](/gaming/check-a-game).

## Games not on Steam

Proton belongs to Steam. Games from other stores use a different launcher that works in a similar way. See [Epic, GOG and other game stores](/gaming/epic-gog-and-others).

If a game will not start after these steps, see [A game will not start](/gaming/game-wont-start).
