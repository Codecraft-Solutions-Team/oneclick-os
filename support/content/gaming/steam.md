Steam on OneClick OS is the same Steam you know. You sign in with the same account, and every game you own is in your library. You do not buy anything again.

## Open Steam

Open Steam from the Start menu, or install it from the App Store if it is not there.

To install it:

1. Open the **App Store** from the Start menu.
2. Search for **Steam** and press **Install**.

Steam is also in the Gamer starter set in the welcome tour. See [Choose your starter apps](/getting-started/choose-starter-apps).

## Sign in

1. Open **Steam**. The first time, it downloads an update for itself. Wait for it to finish.
2. Sign in with your Steam account name and password. If you use Steam Guard, approve the sign-in on your phone or enter the code Steam emails you.
3. Your library appears.

## Install a game

1. Choose **Library**.
2. Choose a game.
3. Press **Install** and confirm where to put it.

Games are downloaded again on this PC. Saved games that use Steam Cloud come back by themselves. Saves that were kept only on your old Windows drive do not, unless you copy them across.

## Games made for Windows

Most games in your library were made for Windows. Steam can run many of them here without any work from you. Some will not run. See [Play Windows games through Steam](/gaming/windows-games-on-steam) and [Which games work and which do not](/gaming/which-games-work).

## Games on a second drive

If your games are on a drive that was set up by Windows, do not point Steam at that folder. Games run from a Windows-formatted drive often fail to start. Let Steam download them again to a folder on the OneClick drive.

## If Steam will not open

Restart the PC and try again. If it still fails, see [An app will not open](/troubleshooting/app-wont-open).

> Note: OneClick OS is an early test version. Whether Steam is already in the Start menu can differ between versions, which is why both ways of getting it are given above.
