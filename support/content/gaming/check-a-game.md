OneClick OS cannot tell you whether a particular game works. Two free websites run by players can. Checking takes about a minute and can save you buying a game you cannot play.

## Step 1: look it up on ProtonDB

1. Go to [protondb.com](https://protondb.com).
2. Type the name of the game in the search box.
3. Read the rating and the most recent reports.

| Rating | What it means |
| --- | --- |
| Native | The game has its own version for systems like this one |
| Platinum | Runs well with nothing to change |
| Gold | Runs well after a small change |
| Silver | Runs, with some problems |
| Bronze | Runs badly or crashes often |
| Borked | Does not run |

Read a few of the newest reports, not only the rating. A game update can change things, and reports tell you which settings people used.

## Step 2: if it is an online game, check the anti-cheat

1. Go to [areweanticheatyet.com](https://areweanticheatyet.com).
2. Search for the game.

A status of **Supported** or **Running** is good. **Broken** or **Denied** means the game does not run, and OneClick OS cannot change that. See [Why some online games will not run](/gaming/anti-cheat).

## Step 3: look at the store page

On [store.steampowered.com](https://store.steampowered.com), a game's page shows its Steam Deck compatibility. The Steam Deck runs games the same way OneClick OS does. "Verified" or "Playable" is a good sign. "Unsupported" is a bad one. It is a hint, not a guarantee, because your PC is not a Steam Deck.

## Keep the refund in mind

Steam has a refund policy for games bought recently and played only briefly. The exact terms are on Steam's own site. If you buy a game and it does not run, ask for the refund promptly instead of spending hours trying to fix it.

## Games on other stores

ProtonDB covers Steam games. For a game from Epic or GOG, a good ProtonDB rating for the same game on Steam is still a useful sign. See [Epic, GOG and other game stores](/gaming/epic-gog-and-others).

> Note: These sites are run by volunteers and are not part of OneClick OS. They report what other players found. Your result can differ.
