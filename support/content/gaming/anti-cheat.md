A small number of very popular online games do not run on OneClick OS. This is not a fault in your PC, and it is not something a setting or an update to OneClick OS can fix.

## The reason

Competitive online games use anti-cheat software to stop cheating. Some of this software runs at the deepest level of Windows, called the kernel. It is written for Windows only and checks that it is running on real Windows. On any other system the check fails and the game refuses to start, or lets you in and then removes you from matches.

Whether a game runs is the game maker's decision. Some anti-cheat systems can be switched on for systems like this one, and many game makers have done so. Others have chosen not to.

## Games known for this

These are commonly known examples that do not run:

- Valorant
- Fortnite
- Recent Call of Duty games
- League of Legends
- Apex Legends

This is not the full list, and it changes over time. Check the current state of any game at [areweanticheatyet.com](https://areweanticheatyet.com).

> Warning: Do not try to get around anti-cheat with tricks you find online. They do not work for these games, and an attempt can get your game account banned.

## What you can do

- **Stream the game.** Cloud gaming runs the game on a Windows computer somewhere else and sends the picture to your browser. Some blocked games are available this way. Which ones depends on the service, so check their site first. See [GeForce NOW](/gaming/geforce-now) and [Xbox Cloud Gaming](/gaming/xbox-cloud-gaming).
- **Keep Windows for that game.** You can have Windows and OneClick OS on the same PC and pick one each time you switch on. See [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).
- **Play something else.** Many online games do allow systems like this one. See [Which games work and which do not](/gaming/which-games-work).

## Check before you buy

If a game is played online against other people, look it up before you spend money. See [Check a game before you buy it](/gaming/check-a-game).
