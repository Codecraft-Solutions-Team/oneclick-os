How well a game runs depends mostly on your PC's graphics card and on the game. OneClick OS cannot make a PC faster than its parts allow. These checks remove the common causes of a game running worse than it should.

## Check the basics first

- **Plug in a laptop.** Most laptops slow the graphics card down on battery. See [Power, sleep and battery](/settings/power-and-battery).
- **Close other apps.** Web browsers with many tabs use a lot of memory. Open **Task Manager** to see what is running. See [Task Manager](/desktop/task-manager).
- **Let downloads finish.** Steam downloading another game in the background slows the one you are playing.
- **Install updates.** System updates include newer graphics drivers. See [How updates work](/updates/how-updates-work).

## Lower the game's own settings

This makes the largest difference. In the game's graphics or video options:

1. Lower the resolution, or turn on an upscaling option such as FSR if the game has one.
2. Turn shadows and anti-aliasing down.
3. Choose a lower overall preset, such as Medium instead of High.
4. Run the game in full screen, not in a window.

## The first few minutes can stutter

Windows games running through Steam often stutter briefly the first time you play, while Steam prepares parts of the game in the background. This usually settles as you play. If Steam shows that it is processing shaders before a game starts, letting it finish helps.

## Check you have the right version for your graphics card

PCs with Nvidia graphics need the Nvidia version of OneClick OS. With the standard version on an Nvidia PC, games can run very poorly or not at all. See [Nvidia graphics](/gaming/nvidia-graphics).

On a laptop with two graphics chips, a game may start on the weaker one. In Steam, check the game's page on [protondb.com](https://protondb.com), where other players with similar laptops often describe what they did.

## Check what other players get

Look the game up on [protondb.com](https://protondb.com). Reports there mention performance and list any settings people changed. If many players with similar PCs report the same slowdown, the cause is the game, not your PC.

## Screen settings

A wrong refresh rate can make a game feel jerky even when it runs well. Open **Settings** and check that your screen is set to its highest refresh rate. See [Screens, resolution and second monitors](/settings/displays).

## If the game is too demanding for the PC

Cloud gaming runs the game on someone else's computer, so your PC's graphics card stops mattering. See [GeForce NOW](/gaming/geforce-now).

> Note: OneClick OS is an early test version and game performance has not been measured across many PCs. If one game runs far worse than on Windows on the same PC, please [report a problem](/troubleshooting/report-a-problem).
