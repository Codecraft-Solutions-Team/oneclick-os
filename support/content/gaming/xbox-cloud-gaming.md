Xbox Cloud Gaming is Microsoft's service for streaming games. The game runs on Microsoft's computers and the picture is sent to your browser. You do not need an Xbox.

## What the shortcut does

**Xbox Cloud Gaming** is pinned in the Start menu. Pressing it opens [xbox.com/play](https://xbox.com/play) in your web browser. Nothing is installed, and OneClick OS has no connection to Microsoft's service.

## What you need

- **A Microsoft account.**
- **Usually a Game Pass subscription.** Microsoft decides which plans include cloud gaming and which games are in it. Check [xbox.com/play](https://xbox.com/play) for the current terms.
- **A controller.** Most games on the service expect one. A few support mouse and keyboard. See [Controllers](/gaming/controllers).
- **A good internet connection.** Wired or strong Wi-Fi.

## Start playing

1. Plug in or connect your controller.
2. Open the **Start menu** and choose **Xbox Cloud Gaming**.
3. Sign in with your Microsoft account.
4. Choose a game and press play.

## If the page does not work in your browser

The service is built mainly for Microsoft Edge and Chrome. If the page says your browser is not supported, or your controller is not picked up, install **Google Chrome** from the App Store and open the page there. See [Your web browser](/apps/web-browser).

## What about the Xbox app and PC Game Pass

The Xbox app for Windows, which downloads Game Pass games to your PC, does not run on OneClick OS. Streaming through the browser is the way to play Game Pass games here. Only games that Microsoft offers for cloud play are available, which is fewer than the full PC Game Pass list.

## Games blocked by anti-cheat

Some games that will not run on OneClick OS can be streamed through this service. Check that the game is offered before you subscribe. See [Why some online games will not run](/gaming/anti-cheat).

> Note: Picture quality and delay depend on your internet connection and Microsoft's service. OneClick OS cannot improve either.

To remove the shortcut, right-click it in the Start menu and choose **Unpin from Start**. See also [GeForce NOW](/gaming/geforce-now).
