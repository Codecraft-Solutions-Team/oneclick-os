title: A game will not start
summary: Steps to try, in order, when a game closes straight away or never opens.
order: 130
---
Work through these in order. Stop when the game starts.

## 1. Find out whether it can run at all

This saves the most time. Some games do not run on OneClick OS whatever you do.

- Look the game up on [protondb.com](https://protondb.com). If the rating is "Borked", or recent reports say it stopped working, the problem is not your PC.
- If it is an online game, look it up on [areweanticheatyet.com](https://areweanticheatyet.com). "Broken" or "Denied" means it will not run, and OneClick OS cannot fix that. See [Why some online games will not run](/gaming/anti-cheat).

## 2. Try the simple things

1. Wait. The first start of a Windows game through Steam can take a few minutes with nothing on screen.
2. Close Steam completely, open it again, and press **Play** once.
3. Restart the PC.
4. Check for a system update, then for app updates. See [Update your apps](/apps/update-apps).

## 3. Check the game's files

1. In your Steam library, right-click the game and choose **Properties**.
2. Choose **Installed Files**.
3. Press the button to verify the integrity of the game files.

Steam downloads again anything that is missing or damaged.

## 4. Try a different compatibility version

1. Right-click the game in Steam and choose **Properties**.
2. Choose **Compatibility**.
3. Tick the option to force a specific Steam Play compatibility tool.
4. Pick a different Proton version from the list, then try the game.

Reports on ProtonDB often say which version worked for other players. See [Play Windows games through Steam](/gaming/windows-games-on-steam).

## 5. Check where the game is installed

A game installed on a drive that was set up by Windows often fails to start. Move it to the OneClick drive. In the game's **Properties**, under **Installed Files**, Steam has an option to move the install folder.

## 6. Check the graphics version

On a PC with Nvidia graphics, games need the Nvidia version of OneClick OS. See [Nvidia graphics](/gaming/nvidia-graphics).

## 7. Games outside Steam

For Epic or GOG games, open the launcher's settings for that game and try a different compatibility version there. See [Epic, GOG and other game stores](/gaming/epic-gog-and-others).

## If none of this works

Some games do not run, and it is better to know that early. If you bought the game recently on Steam and have barely played it, Steam's refund policy may apply. You can also stream the game or keep Windows for it. See [GeForce NOW](/gaming/geforce-now) and [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).

> Note: OneClick OS is an early test version. If a game is reported as working by other players and fails only for you, please [report a problem](/troubleshooting/report-a-problem). See [Find the details we ask for in a report](/troubleshooting/get-details-for-a-report).
