summary: A plain guide to the kinds of games that usually run, sometimes run, and do not run.

---
No list can cover every game, and OneClick OS does not test games itself. This page describes the pattern, so that you know what to expect and where to check.

## Usually works

- **Single-player games on Steam.** Most of these run through Steam's built-in compatibility.
- **Games with a native version for systems like OneClick OS.** Steam shows these and installs that version.
- **Older games.** Games from past years have had longer to be sorted out.
- **Games marked as verified or playable for the Steam Deck.** The Steam Deck is a handheld that runs games the same way OneClick OS does. A good rating there is a good sign here, though it is not a guarantee.

## Sometimes works

- **Brand-new releases.** They may need a few days or weeks before problems are fixed.
- **Games that start through their own launcher,** such as those from EA or Ubisoft. The launcher is often the part that fails.
- **Online games with anti-cheat.** Some are allowed to run by their makers and some are not. Check each one.
- **Games with mods or mod managers.** The game may run while the modding tools need extra work.

## Does not work

- **Games with kernel-level anti-cheat that only allows Windows.** Commonly known examples are Valorant, Fortnite, recent Call of Duty games, League of Legends and Apex Legends. OneClick OS cannot fix this. See [Why some online games will not run](/gaming/anti-cheat).
- **PC Game Pass games installed from the Xbox app.** That app is for Windows only. Many of the same games can be streamed. See [Xbox Cloud Gaming](/gaming/xbox-cloud-gaming).

> Note: These lists change. A game maker can switch support on or off with an update, in either direction.

## How to check one game

Two websites, run by players, keep track:

- [protondb.com](https://protondb.com) shows how well a Steam game runs.
- [areweanticheatyet.com](https://areweanticheatyet.com) shows whether a game's anti-cheat allows it.

See [Check a game before you buy it](/gaming/check-a-game) for how to read them.

## If your main game is on the wrong list

You can stream it if a cloud service carries it, or keep Windows beside OneClick OS and start Windows for that game. See [GeForce NOW](/gaming/geforce-now) and [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).
