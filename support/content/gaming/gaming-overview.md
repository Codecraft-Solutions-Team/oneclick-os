A large share of PC games run on OneClick OS, including many made only for Windows. Some do not, and for a few popular online games there is nothing OneClick OS can do about it. This page gives the honest picture.

## What works

- **Steam games.** Steam runs here, and it can run many Windows games through a compatibility feature built into Steam. See [Set up Steam](/gaming/steam) and [Play Windows games through Steam](/gaming/windows-games-on-steam).
- **Games from Epic, GOG and others.** These use a free launcher from the App Store. See [Epic, GOG and other game stores](/gaming/epic-gog-and-others).
- **Cloud gaming.** GeForce NOW and Xbox Cloud Gaming stream games to your browser. Shortcuts for both are pinned in the Start menu. See [GeForce NOW](/gaming/geforce-now) and [Xbox Cloud Gaming](/gaming/xbox-cloud-gaming).
- **Controllers.** Most common controllers work when you plug them in. See [Controllers](/gaming/controllers).

## What does not work

Some online games use anti-cheat software that only allows Windows. Well-known examples are Valorant, Fortnite, recent Call of Duty games, League of Legends and Apex Legends. These do not run on OneClick OS, and no setting will change that. See [Why some online games will not run](/gaming/anti-cheat).

Other games fail for smaller reasons, such as a launcher that will not start. Some of those can be fixed and some cannot.

## Before you rely on it

OneClick OS cannot promise that any particular game works. Check each game you care about before you switch, and before you buy. It takes a minute. See [Check a game before you buy it](/gaming/check-a-game) and [Which games work and which do not](/gaming/which-games-work).

If one of your main games is on the list that does not work, you have two choices: play it through cloud gaming if the service offers it, or keep Windows on the same PC for that game. See [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).

> Note: OneClick OS is an early test version. Gaming has not been tested on a wide range of PCs yet. If a game that should work does not, see [A game will not start](/gaming/game-wont-start).
