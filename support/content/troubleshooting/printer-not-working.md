## Check the printer first

1. Is it switched on, with no warning light or message on its own screen?
2. Does it have paper and ink or toner? Is there a paper jam?
3. For a USB printer, is the cable pushed in at both ends? Try another USB socket.
4. For a Wi-Fi printer, is it on the same network as the PC? A printer on a guest network cannot be reached from the main one.
5. Turn the printer off, wait ten seconds and turn it on. Then restart the PC.

Most printing problems end here.

## Check you printed to the right printer

In the app's **Print** window, look at which printer is selected. It may be set to save a PDF, or to a printer you no longer have.

## Clear stuck jobs

A job that failed can block everything behind it.

1. Open **Settings** and find the printers page.
2. Open your printer and look at its list of waiting jobs.
3. Cancel them all.
4. Check that the printer is not paused.
5. Print a test page from the same place.

## Remove the printer and add it again

1. On the printers page, remove the printer.
2. Turn the printer off and on.
3. Add it again. See [Add a printer](/settings/printers).

If you are offered more than one entry for the same printer, try the other one. If you are asked for a make and model, pick the closest match.

## The printer was never found

A Wi-Fi printer that has changed network or been reset needs to be joined to your Wi-Fi again, using the printer's own buttons or screen. Try a USB cable to find out whether the printer works at all.

## Prints, but wrongly

- **Blank pages or streaks:** this is ink, toner or the print head. Use the printer's own cleaning function.
- **Pages of odd symbols:** the wrong make and model was chosen. Remove the printer and add it again with a closer match.

> Note: OneClick OS is an early test version. Some printers, mostly older or very cheap models that depend on the maker's Windows software, do not work. A Windows driver from the maker's website cannot be installed here. See [Do I need to install drivers](/windows/drivers).

If it still does not print, please [report the problem](/troubleshooting/report-a-problem) with the make and model of the printer.
