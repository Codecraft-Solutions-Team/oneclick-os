title: Windows is missing from the start-up list
summary: Your Windows files are almost certainly still there. Here is how to get the list back.
order: 170
---
On a PC with both systems, a start-up list lets you pick Windows or OneClick OS each time. If Windows is not on it, or there is no list at all, Windows has usually not been deleted. It has only not been found.

## Is the list hidden

When OneClick OS thinks it is the only system on the PC, it hides the start-up list to save time. When it finds another system, it leaves the list showing.

To show the list by hand, turn the PC on and hold **Shift** or tap **Esc** as it starts.

OneClick OS checks for other systems each time it starts. So restart once more and watch again. The list can appear on the second start after installing.

## Use the PC's own start-up menu

Every PC has its own menu for choosing what to start from. It works even when the OneClick list does not show Windows.

1. Turn the PC on and tap the start-up menu key straight away. It is often **F12**, **F9**, **F8** or **Esc**, depending on the maker.
2. Look for an entry called **Windows Boot Manager**.
3. Choose it. Windows should start.

See [Start your PC from the USB stick](/getting-started/start-from-usb) for how to find the key for your PC.

If **Windows Boot Manager** is listed and works, Windows is intact. You can keep starting it this way while the list is fixed.

## Check your Windows files are there

Start OneClick OS and open **Files**. The Windows disk should appear in the sidebar. If you can open it and see folders such as Users and Windows, your files are there. See [Open your Windows drive from OneClick](/windows/read-windows-drives).

## If Windows is not in either list

- Did you choose to erase the whole disk when installing? That option removes Windows. See [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).
- Is Windows on a second disk that has come loose or been unplugged?

> Warning: Do not reinstall either system to fix this, and do not run repair tools you find online. Both can erase the system you are trying to get back.

## The opposite problem

If the PC goes straight to Windows and OneClick OS is missing, see [Choose Windows or OneClick at start-up](/getting-started/choose-at-startup).

## Tell us

This part of OneClick OS is new and has not been tested on many PCs. Please [report the problem](/troubleshooting/report-a-problem) with the make and model of the PC, and say whether **Windows Boot Manager** appeared in the PC's own menu.
