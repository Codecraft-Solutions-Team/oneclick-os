> Warning: The installer is not available yet. These steps describe how it will work. The exact tool we recommend will be named here when the installer is released.

## What you need

- The installer file from the [Download page](https://oneclickos.org/download). See [Get the installer](/getting-started/get-the-installer).
- A USB stick of 16 GB or more.
- A working computer to prepare the stick on. Your Windows PC is fine.

> Warning: The stick is erased completely. Copy anything you want to keep off it first, and do not use the drive that holds your backup.

## Why you cannot drag the file across

Dragging the installer file onto the stick does not work. The PC would see a stick with one big file on it and would not know how to start from it. A USB writing tool lays the installer out on the stick so that a PC can start from it.

## The steps, in general

1. Install a free USB writing tool on your current computer. There are several well-known ones for Windows. Get it from its maker's own website.
2. Plug in the USB stick.
3. Open the tool and choose the installer file you downloaded.
4. Choose the USB stick as the place to write to. Check the name and size carefully, so you do not pick another drive by mistake.
5. Start the write and wait for it to finish. It can take several minutes.
6. Close the tool and remove the stick safely.

## Afterwards

Windows may say the stick needs to be formatted, or may show it as nearly empty. That is expected. Do not format it. Windows cannot read the way the stick is now laid out.

When you no longer need the installer, you can format the stick in Windows or OneClick OS and use it as a normal stick again.
