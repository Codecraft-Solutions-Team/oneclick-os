> Warning: The installer is not available yet. This page describes how keeping Windows will work. The installer screens are not final, so the steps are kept general.

You do not have to give up Windows. Both systems can live on the same PC, and you pick one each time it starts. This is useful for the few things that only run on Windows, such as games with kernel anti-cheat.

## Prepare in Windows first

1. **Back up your files** to a separate drive. See [Back up your files before installing](/getting-started/back-up-first).
2. **Make a Windows recovery drive.** Search for **Recovery Drive** in the Windows Start menu. It needs its own USB stick.
3. **Find your BitLocker recovery key**, if your drive is encrypted. Windows may ask for it after the start-up arrangement changes. Your Microsoft account page lists it.
4. **Check free space.** OneClick OS needs room of its own. Delete or move what you do not need, then empty the Recycle Bin.
5. **Shut Windows down fully.** Hold **Shift** while you choose **Shut down**. A normal shut down can leave Windows half asleep, with its drive locked.

## During the install

Follow [Install OneClick OS on a PC](/getting-started/install-on-a-pc). At the disk question, choose to keep Windows and not to replace it. Read that screen slowly. Choosing to replace Windows erases it.

## Afterwards

- Each time the PC starts, a short list lets you pick a system. See [Choose Windows or OneClick at start-up](/getting-started/choose-at-startup).
- Each system has its own apps and settings. Programs installed in Windows do not appear in OneClick OS.
- You can open your Windows files from OneClick OS. See [Open your Windows drive from OneClick](/windows/read-windows-drives).
- The clock may be wrong in one system after using the other. See [The clock is wrong after using Windows](/troubleshooting/clock-wrong-after-windows).

> Note: A large Windows update can sometimes change the start-up list. If Windows or OneClick OS goes missing from it, see [Windows is missing from the start-up list](/troubleshooting/windows-missing-from-startup).

## An even safer option

If you have a spare PC or an external USB drive, install OneClick OS there. Your Windows disk is then never touched.
