OneClick OS starts with the built-in tools and little else. The **Your apps** page of the welcome tour lets you add the apps you want in one go, so you do not have to find them one at a time.

## Pick and install

1. Open the **Welcome** app from the Start menu, if it is not already open, and go to **Your apps**.
2. Under **Starter sets**, click a set to tick everything in it. Or tick single apps in the list below.
3. Press **Install selected apps**.
4. Keep using the PC. Notifications show progress as each app installs.

**Clear** unticks everything. Picking a set replaces the ticks you had, so choose a set first and then add or remove single apps.

You need an internet connection. Some apps are large, so this can take a while.

## The starter sets

| Set | What is in it |
|---|---|
| **Everyday** | Firefox, LibreOffice, VLC, Spotify |
| **Gamer** | Steam, Heroic Games Launcher, Lutris, Bottles, Discord, OBS Studio |
| **Work** | LibreOffice, Zoom, Thunderbird |
| **Creator** | GIMP, Krita, Kdenlive, Audacity, OBS Studio, Blender, Inkscape |

## Already there

The page also lists things that need no install:

- A photo viewer and a PDF reader.
- Controller support.
- Web shortcuts to Word, Excel and PowerPoint in the Start menu.
- OneDrive and Google Drive, set up in **Settings** under **Cloud Drives**.
- Shortcuts to GeForce NOW and Xbox Cloud Gaming in the Start menu.
- Web shortcuts to Claude and ChatGPT. These are optional and can be unpinned.

## Change your mind later

Nothing here is final. Every app on this page comes from the App Store, so you can add or remove any of them at any time. See [Install apps from the App Store](/apps/install-apps) and [Remove an app](/apps/remove-apps).

## If an install fails

The page tells you if the installer stopped early. Your choices are kept, so press **Install selected apps** again. If it keeps failing, install the app from the **App Store** instead.

> Note: The [Apps page](https://oneclickos.org/apps) on the website also lets you tick apps before you download. Installing those picks on first start is still being built.
