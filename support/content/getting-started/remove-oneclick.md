title: Remove OneClick OS and go back to Windows
summary: There is no uninstall button. Going back means reinstalling Windows, or deleting OneClick's part of the disk.
order: 160
---
OneClick OS is a whole system, not a program, so it cannot be uninstalled from a list of apps. How you go back depends on how you installed it.

> Warning: Copy your files off the PC first. Both routes below erase everything stored in OneClick OS. See [Back up your files](/updates/back-up-your-files).

## If you replaced Windows

Windows is no longer on the disk, so it has to be installed again.

1. On any working computer, go to Microsoft's download page at [microsoft.com/software-download](https://www.microsoft.com/software-download) and follow the instructions there to make a Windows installer on a USB stick.
2. Start the PC from that stick. The method is the same as in [Start your PC from the USB stick](/getting-started/start-from-usb).
3. Follow the Windows installer. It erases the disk and puts Windows back.

Most PCs that came with Windows 10 or 11 activate again by themselves once they are online. If yours came with an older Windows, find your licence key first.

You will need to reinstall your Windows programs and copy your files back from your backup.

## If you kept Windows beside OneClick

Windows is still there. Removing OneClick OS means two jobs:

1. Deleting the parts of the disk that OneClick OS uses and giving the space back to Windows. This is done in Windows, in **Disk Management**.
2. Making the PC start straight into Windows again, with no start-up list.

The second job is the difficult one. Done in the wrong order, the PC may not start at all until it is repaired from a Windows recovery drive. We do not have tested steps for this yet, and we would rather say so than guess.

Until tested steps exist, the low-risk choice is to leave OneClick OS where it is and pick Windows at start-up. See [Choose Windows or OneClick at start-up](/getting-started/choose-at-startup). If you do go ahead, have a full backup and a Windows recovery drive ready before you delete anything.

## If you installed to an external drive

Unplug the drive. Your PC starts Windows as it always did. You can format the drive later to reuse it.

## Tell us why

If you are leaving because something did not work, please [report it](https://oneclickos.org/report). You do not need an account, and it helps the next person.
