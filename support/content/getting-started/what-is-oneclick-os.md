OneClick OS is a free system that runs your PC in place of Windows, or beside it. It has a Start menu, a taskbar at the bottom, and window buttons where you expect them. It costs nothing and needs no account.

> Warning: OneClick OS is an early test version. The installer for PCs is not available yet. See [What "early test version" means](/getting-started/test-version).

## What you get

- A desktop that looks and works like the one you know. See [A tour of the desktop](/desktop/desktop-tour).
- An **App Store** for installing apps, so you do not hunt for installers on websites.
- Updates that never install themselves. You check, you choose, and you can undo. See [How updates work](/updates/how-updates-work).
- Graphics drivers and game tools already in place.
- A way to run many Windows programs. See [Run Windows programs](/apps/windows-programs).

## What it never does

- It sends nothing about you or your PC to us. There is no usage tracking and no crash reports are uploaded.
- It does not ask you to sign in to an online account.
- It does not force an update or a restart.
- It has no AI features built into the system. There are two optional web shortcuts, to Claude and ChatGPT, which you can unpin.

## What it cannot do

Some things made only for Windows do not run. This is said up front so you can decide before you install.

- Online games that use kernel anti-cheat do not run.
- Adobe apps do not run.
- The desktop versions of Microsoft Office do not run. LibreOffice and Office on the web cover most needs.
- Some devices, such as certain fingerprint readers, have no drivers.

The full list is in [What does not work, and what to use instead](/windows/what-does-not-work).

## What it is built on

Nobody writes an operating system from nothing. OneClick OS stands on Linux, and more exactly on Fedora, Bazzite and the KDE Plasma desktop, which thousands of people have built and given away freely. Our part is the layer you see and touch: the look, the icons, the start-up, the Update page, the plain names and the choices made for you. Our own code is open for anyone to read.

You do not need to know any of those names to use it. They are in the [word list](/windows/word-list) if you meet them elsewhere.
