title: Back up your files before installing
summary: Copy everything you cannot lose to a separate drive or the cloud before you touch the installer.
order: 50
---
Installing an operating system changes the disk you install it on. If you replace Windows, or pick the wrong disk, everything on that disk is erased and cannot be recovered. Back up first, every time.

## What to copy

In Windows, open **File Explorer** and look in your user folder. Copy these:

- Documents
- Pictures
- Desktop
- Downloads
- Music
- Videos

Also think about files that live elsewhere:

- Saved games that are not stored online.
- Folders you made yourself on the C drive or on other drives.
- Files that belong to other people who use the PC. Each person has their own user folder.
- Bookmarks and passwords in your web browser. See [Move bookmarks and passwords](/windows/move-browser).

## Where to copy it

Use a place that is separate from the PC:

- An external hard drive or a large USB stick.
- A cloud service such as OneDrive or Google Drive. Wait until it says everything has finished uploading.

> Warning: Do not use the USB stick you plan to turn into the installer. That stick is erased.

## Check the backup

1. Unplug the backup drive and plug it into another device if you can.
2. Open a few files from different folders.
3. Compare the size of the backup with the size of the originals. They should be close.

A backup you have not opened is only a hope.

## If you are keeping Windows

Back up anyway. Making room beside Windows changes the same disk, and a slip can still cost you your files. Also make a Windows recovery drive. Search for **Recovery Drive** in the Windows Start menu.

## After installing

Your backup is also how your files get onto OneClick OS. See [Move your files from Windows](/windows/move-your-files). To keep backing up afterwards, see [Back up your files](/updates/back-up-your-files).
