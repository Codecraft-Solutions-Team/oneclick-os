You chose a language and a keyboard layout during first-time setup. Both can be changed later.

## Change the keyboard layout

The layout decides which character each key types. If `@` and `"` are swapped, or the wrong currency sign appears, the layout does not match your keyboard.

1. Open the **Start menu** and type `keyboard`.
2. Choose **Keyboard**.
3. Open the layouts section.
4. Add the layout that matches your keyboard, for example English (Australian), English (UK) or English (US).
5. Remove the one you do not want, or move yours to the top.
6. Apply the change.

## Use more than one layout

Add each layout you need on the same page. When there is more than one, a small layout marker appears with the icons beside the clock. Choose it to switch. The Keyboard page also lets you set a key combination for switching.

## Change the language

1. Open **Settings** and find the language and region page. Typing `language` in the Settings search box is the quickest way.
2. Choose your language.
3. Apply, then sign out and back in. Open apps keep the old language until then.

The same page sets the formats for dates, numbers and currency. These can differ from the language, for example English text with Australian dates.

> Note: Some apps do not include every language. Where a translation is missing, that part appears in English.

## Other keyboard settings

The Keyboard page also sets how quickly a held key repeats. For key combinations, see [Keyboard shortcuts](/desktop/keyboard-shortcuts).
