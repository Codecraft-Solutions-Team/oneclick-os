The Windows Apps page decides what happens when you double-click a Windows program, which is a file ending in `.exe` or `.msi`.

## Open it

Open **Settings** and choose **Windows Apps**. You can also type `windows apps` in the Start menu.

## The switch

At the top is a switch called **Open Windows .exe and .msi programs**.

- **On:** double-clicking a Windows installer or program launches it with Bottles. If Bottles is not installed, you are asked whether you want to install it.
- **Off:** double-clicking the file opens it as an archive so you can look inside. It does not run.

## Bottles

Bottles is a free app that runs Windows programs on OneClick OS. The page tells you whether it is installed.

- **Install Bottles from App Store** opens the App Store so you can install it. Nothing is installed unless you choose to.
- **Check again** looks once more, for example after you have just installed it.
- **Open Bottles** opens the app once it is there.

See [Set up Bottles for Windows programs](/apps/bottles).

## What to expect

Many Windows programs run this way, and many do not. It depends on the program. Programs that need special Windows drivers, such as some anti-cheat systems and some hardware tools, will not run. See [Run Windows programs](/apps/windows-programs) and [What does not work, and what to use instead](/windows/what-does-not-work).

> Note: OneClick OS is an early test version. This page is new, and running a Windows program through it has not been fully tested on every PC.

> Note: In the preview that runs on a Mac, this page shows a message that Windows programs cannot run there. That is a limit of the Mac's processor. Windows programs are supported on the PC version.

Before reaching for a Windows program, check the **App Store**. There is often a version made for OneClick OS that works better.
