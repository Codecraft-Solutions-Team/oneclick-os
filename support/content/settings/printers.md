Most printers made in the last several years work without installing anything. You do not download a driver from the maker's website. See [Do I need to install drivers](/windows/drivers).

## A printer on your Wi-Fi or network

1. Turn the printer on and make sure it is on the same network as the PC.
2. Open a document and choose **Print**.
3. Look for the printer in the list. Network printers are often there already.

If it is not listed, add it in Settings.

## Add a printer in Settings

1. Open **Settings** and find the printers page. Typing `printer` in the Settings search box is the quickest way.
2. Choose to add a printer.
3. Pick yours from the printers that are found.
4. If you are asked for a make and model, choose the closest match.
5. Enter your password if asked. Adding a printer changes the system, so it needs an administrator.

## A printer on a USB cable

Plug it in and turn it on, then follow the same steps. It should appear in the list of printers found.

## Print a test page

After adding the printer, open its entry on the printers page and print a test page. If it comes out, you are finished.

## Scanning

A printer with a scanner built in is set up separately for scanning. See [Scan a document](/settings/scanners).

> Note: OneClick OS is an early test version. Some printers, mostly older or very cheap models that depend on the maker's Windows software, do not work.

If the printer is found but nothing prints, see [The printer is not working](/troubleshooting/printer-not-working).
