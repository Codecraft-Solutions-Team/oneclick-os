About This PC shows which version of OneClick OS you have and the main parts inside the computer. It is the page to open when someone asks "what PC do you have".

## Open it

1. Open the **Start menu** and type `about`.
2. Choose **About This PC**.

You can also open **Settings** and find it in the list of pages.

## What it shows

- The OneClick OS name and logo.
- The version of OneClick OS.
- The edition. This is **Desktop** on a PC and **Preview** in the browser and virtual machine preview.
- A link to the project.
- Hardware details, such as the processor, the amount of memory and the graphics.

There is a button for copying the details, which is handy when you are filling in a report.

> Note: Parts of this page still use the wording it came with. The window may be titled "About this System", and one section lists the versions of the underlying software OneClick OS is built on. Those lines are correct, they are only not in OneClick's plain wording yet.

## Where else to find the version

Open **Settings** and choose **Update**. The page says "You have OneClick OS" followed by the version number. That is the number the report form asks for.

## More detail about the hardware

The **About This PC** app in the Start menu goes further, with separate pages for things like devices, graphics and network. Most people never need it, but it helps when working out whether a part is supported.
