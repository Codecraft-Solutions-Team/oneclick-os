title: Zip and unzip files
summary: Extract and make zip files from the right-click menu in Files, or with the Archives app.

Zip files work on OneClick OS much as they do on Windows. The built-in app for them is called **Archives**. It opens `.zip` files and other common kinds such as `.7z` and `.tar.gz`.

> Note: OneClick OS is an early test version. The exact wording of the right-click options may differ a little from what is described here.

## Unzip a file

1. Open **Files** and find the zip file.
2. Right-click it.
3. Choose the extract option, and extract it here or into a folder of its own.

A new folder with the contents appears beside the zip file. The zip file itself is left as it was. You can delete it once you have checked the contents.

## Look inside without unzipping

Double-click the zip file. It opens in **Archives** and shows what is inside. From there you can extract everything, or drag single files out into a folder.

## Make a zip file

1. In **Files**, select the files or folders you want. Hold **Ctrl** and click to select several.
2. Right-click the selection.
3. Choose the compress option, and pick ZIP as the type.

The new zip file appears in the same folder. ZIP is the type to choose when sending files to people on Windows or Mac, because every computer can open it.

## Password-protected zip files

When you open a protected zip, you are asked for the password. To make one, open **Archives** from the Start menu and create a new archive there. The password setting is among the options when you create it.

## RAR files

`.rar` files can usually be opened but not created. If one will not open, ask the sender for a `.zip` instead.

## A note on Windows installers

A `.exe` or `.msi` file is a Windows program, not an archive. Double-clicking one offers to run it with Bottles. If you have switched that off in **Settings** under **Windows Apps**, the file is opened as an archive instead. See [Run Windows programs](/apps/windows-programs).

For more on working with files and folders, see [Find and manage your files](/desktop/files).
