**Bottles** is a free app that runs Windows programs on OneClick OS. It is not made by OneClick OS. Its own site is [usebottles.com](https://usebottles.com). It is not installed until you choose to install it.

## Install Bottles

There are three ways. All of them end at the same App Store page.

- **From Settings.** Open **Settings**, choose **Windows Apps**, and press **Install Bottles from App Store**.
- **From a Windows file.** Double-click any `.exe` or `.msi` file and say yes when asked whether to open the App Store to install Bottles.
- **From the App Store.** Open the **App Store**, search for **Bottles**, and press **Install**.

When it has finished, go back to **Settings**, **Windows Apps**, and press **Check again**. The page then says that Bottles is installed and ready, and the button changes to **Open Bottles**.

## The first time you open Bottles

Bottles downloads some extra parts the first time it starts. This needs an internet connection and can take several minutes. Let it finish.

Bottles keeps each Windows program in its own container, which it calls a bottle. Think of a bottle as a small pretend Windows drive. Bottles guides you through making the first one and asks what kind of program it is for.

## Run a program

After setup, double-click a `.exe` or `.msi` file in **Files**. It opens in Bottles. If the file is an installer, the program it installs lives inside the bottle and is started from Bottles afterwards.

## If a program does not work

- Try it in a new, separate bottle.
- Check that you have the right installer for the program.
- Accept that some programs will not run. Desktop Microsoft Office and Adobe apps are known not to work.

Bottles only works on PCs with an Intel or AMD processor.

> Note: Bottles is for ordinary programs. For games, Steam does a better job. See [Play Windows games through Steam](/gaming/windows-games-on-steam).
