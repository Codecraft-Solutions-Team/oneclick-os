On OneClick OS you do not download installers from websites. Apps come from one place, the **App Store**. It is free to use and needs no account.

## Install an app

1. Open the **App Store** from the Start menu.
2. Type the name of the app in the search box, or browse the categories.
3. Choose the app to read about it.
4. Press **Install**.

When the install finishes, the app appears in the Start menu. You can also find it by typing its name in the Start menu search.

> Note: You need an internet connection. Large apps can take a few minutes to download.

## Install several apps at once

The welcome tour has a page of starter apps. Tick the ones you want, or pick a starter set, then press **Install selected apps**. They install in the background while you keep working. You can open the tour again at any time by opening **Welcome** from the Start menu. See [Choose your starter apps](/getting-started/choose-starter-apps).

## If you cannot find an app

Not every Windows app has a version for OneClick OS. Often there is a different app that does the same job. See [An app I need is not in the App Store](/apps/app-not-in-store).

## Keeping apps up to date

Apps do not update themselves. You update them in the App Store when you choose to. See [Update your apps](/apps/update-apps).

> Note: OneClick OS is an early test version. If an app will not install, check your internet connection and try again, then [report a problem](/troubleshooting/report-a-problem) if it still fails.
