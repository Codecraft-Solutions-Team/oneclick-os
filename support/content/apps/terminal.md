title: The Terminal, and why you do not need it
summary: The Terminal is a place to type commands. Everyday use of OneClick OS never requires it.
order: 200
---
The **Terminal** is a window where you type commands instead of clicking. It is the same idea as Command Prompt or PowerShell on Windows. It is pinned in the Start menu because some people like it, not because you need it.

## You can ignore it

OneClick OS is built so that ordinary jobs are done with the mouse:

| Job | Where you do it |
| --- | --- |
| Install, update or remove apps | **App Store** |
| Update the system, or undo an update | **Update** |
| Wi-Fi, sound, screens, printers | **Settings** |
| Run a Windows program | Double-click it, or **Settings**, **Windows Apps** |
| Connect OneDrive or Google Drive | **Settings**, **Cloud Drives** |
| Close an app that has frozen | **Task Manager** |

If you find a job that seems to need the Terminal, that is a gap we want to know about. Please [report a problem](/troubleshooting/report-a-problem).

## Why guides on the internet use it

Search for help and you will find many pages that tell you to paste commands. There are two reasons. A command is the same on every system, so it is quicker to write down than a series of clicks. And most of those guides were written for other systems, not for OneClick OS.

Many of those commands will not work here. The system files of OneClick OS are protected and cannot be changed by a command, which is part of how an update can be undone. See [How updates work](/updates/how-updates-work).

## Be careful with pasted commands

> Warning: Do not paste a command into the Terminal unless you trust where it came from and understand roughly what it does. A command runs straight away with no undo. Be especially careful with any command that starts with `sudo` and asks for your password, because that gives it permission to change far more.

If a website tells you to install an app with a command, look for the app in the App Store first. See [An app I need is not in the App Store](/apps/app-not-in-store).

## If you want to try it

Open **Terminal** from the Start menu. You see a short welcome line and a place to type. Type `exit` and press **Enter** to close it, or close the window. Opening it changes nothing on its own.
