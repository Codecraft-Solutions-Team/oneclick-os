OneClick OS uses **LibreOffice** for office documents. It is free, works without an account, and works offline.

## It installs itself the first time you sign in

LibreOffice is downloaded and installed the first time you sign in, as long as the PC is online. You see a small progress window while this happens. If the PC was offline, or LibreOffice is not in the Start menu, install it from the App Store. See [Install apps from the App Store](/apps/install-apps).

> Note: OneClick OS is an early test version. The automatic install is new and has not been tested on many PCs yet. If it did not happen for you, installing LibreOffice from the App Store gives the same result.

## Open a file

Double-click the file in **Files**. These types open in LibreOffice:

| File type | Opens in |
| --- | --- |
| `.docx`, `.doc`, `.odt`, `.rtf` | the word processor (Writer) |
| `.xlsx`, `.xls`, `.ods`, `.csv` | the spreadsheet (Calc) |
| `.pptx`, `.ppt`, `.odp` | presentations (Impress) |

## Save so that Office users can open it

If you opened a `.docx`, `.xlsx` or `.pptx` file, LibreOffice saves it in the same format. When you save, it asks whether to keep the current format. Choose to keep it if you are sending the file to someone who uses Microsoft Office.

For a new document, choose **File**, then **Save As**, and pick the Word, Excel or PowerPoint format from the file type list.

## What can look different

Most documents open looking the same. A few things can shift:

- **Fonts.** If the document uses a font that is not on this PC, a similar one is used and line breaks can move.
- **Complicated layouts.** Documents with many text boxes, tracked changes or unusual tables may need tidying.
- **Macros.** Excel macros often do not run.

If a document must look exactly as it does in Microsoft Office, open it in the browser version instead. See [Use Microsoft Office on the web](/apps/office-on-the-web).

The desktop version of Microsoft Office cannot be installed on OneClick OS. See [Microsoft Office](/windows/microsoft-office).
