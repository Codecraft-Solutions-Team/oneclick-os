summary: What to try when an app is missing, from web versions to alternatives to Bottles.

---
Some apps are made only for Windows or Mac. If a search in the App Store finds nothing, work through these options in order.

## 1. Check the name

Search for the kind of app, not only the brand. For example, search "video editor" or "pdf". Trying a few everyday words often brings up several free apps in the App Store catalogue that do the same job.

## 2. Use the web version

Many services work fully in a web browser, with nothing to install. Examples are Microsoft Office, Google Docs, WhatsApp, Microsoft Teams and most banking and streaming sites. OneClick OS includes Start menu shortcuts for Word, Excel and PowerPoint. See [Use Microsoft Office on the web](/apps/office-on-the-web).

## 3. Use a different app that does the same job

| You used | Try |
| --- | --- |
| Microsoft Office | LibreOffice, or Office on the web |
| Photoshop | GIMP or Krita |
| Premiere Pro | Kdenlive |
| Illustrator | Inkscape |
| Outlook | Thunderbird, or your email in the browser |

All of these are free in the App Store. See [What does not work, and what to use instead](/windows/what-does-not-work).

## 4. Try the Windows version in Bottles

If you have the Windows installer (a `.exe` or `.msi` file), double-click it. OneClick OS offers to run it with a free app called Bottles. Many Windows programs work this way, but not all. Desktop Microsoft Office and Adobe apps do not. See [Run Windows programs](/apps/windows-programs).

## 5. Keep Windows for that one app

If you cannot do without a program and nothing above works, you can keep Windows on the same PC and choose which one to start. See [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).

> Warning: Be careful with websites that tell you to paste commands into the Terminal to install an app. A wrong command can do damage. Apps from the App Store never need this.

> Note: Some apps in the App Store catalogue are packaged by volunteers, not by the original company. The app's page says who publishes it.
