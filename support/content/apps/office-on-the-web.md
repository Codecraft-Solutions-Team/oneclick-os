The desktop version of Microsoft Office does not run on OneClick OS. The browser version does. It is the real Word, Excel and PowerPoint, made by Microsoft, running in a web page.

## Open it

OneClick OS includes three shortcuts:

- **Word on the web**
- **Excel on the web**
- **PowerPoint on the web**

1. Open the **Start menu**.
2. Type **Word**, **Excel** or **PowerPoint** in the search box.
3. Choose the shortcut. It opens in your web browser.
4. Sign in with your Microsoft account.

You can also go to [office.com](https://office.com) in the browser yourself. The shortcuts do nothing more than open that site.

## What you need

- An internet connection. Office on the web does not work offline.
- A Microsoft account. The shortcuts are not an Office licence. Microsoft decides what is free and what needs a paid plan.

## Where your files are

Office on the web opens files stored in OneDrive. To work on a file that is on this PC, upload it to OneDrive first. You can make OneDrive appear as a folder in Files, see [Connect OneDrive](/apps/onedrive).

## Web version or LibreOffice

| | Office on the web | LibreOffice |
| --- | --- | --- |
| Works offline | No | Yes |
| Needs an account | Yes | No |
| Layout matches Microsoft Office | Yes | Usually |
| Opens files on this PC directly | No, upload first | Yes |

Many people use both: LibreOffice for everyday files, and the web version when a document must look exactly right. See [Open and edit Word, Excel and PowerPoint files](/apps/libreoffice).

> Note: The web versions have fewer features than desktop Office. Some advanced tools, such as Excel macros, are missing. See [Microsoft Office](/windows/microsoft-office).
