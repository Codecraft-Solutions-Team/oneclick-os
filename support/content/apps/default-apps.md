Every type of file has a default app, the one that opens when you double-click. You can use a different app once, or change the default.

## What OneClick OS sets for you

| File type | Opens with |
| --- | --- |
| Word documents (`.docx`, `.doc`, `.odt`, `.rtf`) | LibreOffice |
| Spreadsheets (`.xlsx`, `.xls`, `.ods`, `.csv`) | LibreOffice |
| Presentations (`.pptx`, `.ppt`, `.odp`) | LibreOffice |
| Windows programs (`.exe`, `.msi`) | The Windows program opener, which uses Bottles |

Other file types use the usual built-in app for that type.

## Open a file with a different app, once

1. In **Files**, right-click the file.
2. Choose **Open With**.
3. Pick an app from the list.

This does not change the default. The next double-click uses the usual app.

## Change the default for a file type

1. In **Files**, right-click a file of that type.
2. Choose **Properties**.
3. Next to the file type, use the option to change which app opens it.
4. Move the app you want to the top of the list and confirm.

From then on, every file of that type opens in the app you chose.

> Note: OneClick OS is an early test version. The wording in these windows has not been tidied yet and may differ slightly from the steps above.

## If the app you want is not in the list

Install it first. Open the **App Store**, search for it, and press **Install**. Then come back and it will be in the list. See [Install apps from the App Store](/apps/install-apps).

## Web links and the default browser

Which browser opens when you click a link is set from the browser itself. See [Your web browser](/apps/web-browser).

## Windows programs

To change what happens when you double-click a `.exe` or `.msi` file, do not use the steps above. There is a switch for it: open **Settings**, choose **Windows Apps**, and use **Open Windows .exe and .msi programs**. See [The Windows Apps page](/settings/windows-apps-page).
