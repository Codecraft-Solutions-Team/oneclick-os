OneClick OS is not Windows, so Windows programs do not run on their own. A free app called **Bottles** can run many of them. OneClick OS connects the two for you.

## What happens when you double-click a Windows program

1. Double-click a `.exe` or `.msi` file in **Files**.
2. If Bottles is installed, the file opens in Bottles.
3. If Bottles is not installed, you are told that the file is a Windows program and that Bottles needs to be installed once. Say yes and the App Store opens on Bottles. Press **Install**, then double-click the file again.

Nothing is installed unless you agree. For the first-time setup, see [Set up Bottles for Windows programs](/apps/bottles).

## What works and what does not

Be ready for some programs to fail. There is no list that OneClick OS can promise.

- **Often works:** smaller and older programs, simple tools, many offline installers.
- **Does not work:** the desktop version of Microsoft Office, and Adobe apps such as Photoshop and Premiere Pro. See [Microsoft Office](/windows/microsoft-office) and [Photoshop and other Adobe apps](/windows/adobe).
- **Does not work:** programs that install Windows drivers, such as some hardware utilities and antivirus programs.
- **Games:** use Steam for games, not Bottles. See [Play Windows games through Steam](/gaming/windows-games-on-steam).

Before trying the Windows version, check whether the App Store has the same app or a good replacement. An app from the App Store will always work better. See [An app I need is not in the App Store](/apps/app-not-in-store).

## Only on Intel and AMD PCs

Windows programs are built for Intel and AMD processors. On a PC with one of those, this feature is available. On the Arm preview that runs on Apple computers, you are told that Windows programs cannot run there.

## Turn it off

If you would rather Windows files did not open this way, open **Settings**, choose **Windows Apps**, and switch off **Open Windows .exe and .msi programs**. See [The Windows Apps page](/settings/windows-apps-page).

> Warning: A Windows program from an untrusted website can still be harmful to your files. Only run installers from the real maker of the program.

> Note: OneClick OS is an early test version, and this feature is new. It may not be finished.
