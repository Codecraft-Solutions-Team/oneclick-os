In Windows you often install a program by finding its website, downloading a setup file and clicking through an installer. In OneClick OS you open the **App Store** and press install. That is the whole job.

## How to install an app

1. Open the **App Store** from the Start menu.
2. Search for the app by name, or browse.
3. Press the install button.

The app then appears in the Start menu. See [Install apps from the App Store](/apps/install-apps).

## Why it works this way

- **You get the real app.** Searching the web for a download is how people end up on fake sites with look-alike installers. The App Store has one listing for each app.
- **No extras.** Nothing arrives with a toolbar, a trial or a second program you did not ask for.
- **One place for updates.** Every app updates from the App Store when you choose. Apps do not each run their own updater in the background. See [Update your apps](/apps/update-apps).
- **Clean removal.** Removing an app removes it. There are no leftovers to hunt for.
- **Apps are kept apart from the system.** An app cannot change the core of the system, so a bad app cannot break your PC's ability to start.

See [Where apps come from and whether they are safe](/apps/where-apps-come-from).

## What happens with a Windows setup file

A .exe or .msi file is a Windows program. OneClick OS does not ignore it.

- If Bottles is installed, double-clicking the file opens it with Bottles.
- If Bottles is not installed, you are asked whether you want to install it.
- On a PC with an Arm processor, you are told plainly that Windows programs cannot run.

Many Windows programs work this way, but not all. Always look in the App Store first. A version made for this system works better than a Windows version run through Bottles. See [Run Windows programs](/apps/windows-programs).

## If the app is not in the App Store

Do not run commands copied from a website you do not know. See [An app I need is not in the App Store](/apps/app-not-in-store) for the safe options, which include using the web version of the app.

> Note: You do not need the Terminal to install apps. If a guide tells you to paste commands into it, that guide was written for a different system and may not suit OneClick OS.
