OneClick OS is laid out like Windows on purpose. Underneath it is a different system, and a few things work differently. These are the ones you are likely to meet.

## Apps come from the App Store

You do not download installers from websites. You open the **App Store**, find the app and press install. Updates for apps come from the same place. See [Why you do not download installers from websites](/windows/installing-is-different).

## Updates wait for you

Nothing downloads, installs or restarts until you ask. Each update keeps the version you had before, so you can go back. See [How updates work](/updates/how-updates-work).

## No drive letters

There is no C drive or D drive. Your own files live in your **Home** folder, and other drives appear by name in **Files**. See [Where is the C drive](/windows/drive-letters).

## No online account

You sign in with an account that exists only on the PC. Nothing asks for an email address. Nothing about how you use the PC is sent to us.

## Your password is asked for more often

Changing something that affects the whole system, such as installing an update, asks for your password. This is the system checking that it is really you. It is normal.

## Capital letters matter in file names

`Report.docx` and `report.docx` are two different files and can sit in the same folder. In Windows they would be the same file.

## The system looks after itself

The core of the system is kept separate from your files and apps. Apps cannot change it, and an update replaces it as one whole piece. This is why an update can be undone cleanly. You do not need to clean a registry, defragment the disk or run tune-up tools.

## Some Windows software does not run

Many Windows programs and games work, but not all. Games with kernel anti-cheat, Adobe apps and desktop Microsoft Office do not. See [What does not work, and what to use instead](/windows/what-does-not-work).

## What stays the same

- The Start menu, the taskbar and the clock are where you expect them.
- Double-click opens files and folders.
- Close, maximise and minimise are at the top right of each window.
- Ctrl+C, Ctrl+V, Ctrl+Z and Alt+Tab do what they always did.
- Ctrl+Shift+Esc opens Task Manager.

For a name-by-name match, see [Where things went: a Windows to OneClick list](/windows/windows-to-oneclick).
