Your bookmarks and saved passwords belong to your web browser, not to Windows. So they move with the browser, in one of two ways.

## The easy way: browser sync

Firefox, Chrome, Edge and Brave can all keep your bookmarks and passwords in a browser account and copy them to any computer you sign in on.

1. In Windows, open your browser and check that you are signed in to its sync and that it has finished syncing.
2. In OneClick OS, install the same browser from the **App Store** if it is not already there. See [Your web browser](/apps/web-browser).
3. Sign in to the same browser account.

Your bookmarks, passwords and history appear after a short wait. You do not have to use the same browser as before, but sync only works between copies of the same browser.

## The manual way: export and import

Use this if you do not want a browser account, or if you are changing to a different browser.

### Bookmarks

1. In Windows, open the browser's bookmarks or favourites manager.
2. Choose the option to export bookmarks. It saves one HTML file.
3. Copy that file to a USB stick or a cloud drive.
4. In OneClick OS, open your browser's bookmarks manager and choose the option to import bookmarks from an HTML file.

### Passwords

1. In Windows, open the browser's password settings.
2. Choose the option to export passwords. It saves one CSV file.
3. Move the file across and import it in the browser's password settings in OneClick OS.

> Warning: An exported password file is not protected. Anyone who opens it can read every password. Delete it from the USB stick, from Downloads and from Trash as soon as you have imported it.

The exact menu names differ from browser to browser and change over time. Search the browser's own help for "export bookmarks" or "export passwords" if you cannot find them.

## If you use a password manager

A separate password manager, such as Bitwarden, is not tied to your browser. Install it in OneClick OS, or add its extension to your browser, and sign in.

## Write down what matters first

Before you erase Windows, check that you can sign in to your email and your browser account from another device. If you cannot, sort that out first. Those two accounts are how you get back into everything else.
