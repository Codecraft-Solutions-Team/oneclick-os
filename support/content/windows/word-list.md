## Words used in OneClick OS

| Word | What it means |
|---|---|
| **Start menu** | The menu at the bottom left. It holds your pinned apps, all apps, search, and the power buttons. |
| **Taskbar** | The bar along the bottom with Start, your open windows, and the clock. |
| **Files** | The app for looking through folders and drives. Like File Explorer. |
| **Home folder** | Your own folder, holding Documents, Pictures, Downloads and the rest. |
| **App Store** | Where you install, update and remove apps. |
| **Settings** | The one place for all settings. |
| **Update** | The Settings page that checks for and installs system updates. |
| **About This PC** | Shows the OneClick version and what hardware the PC has. |
| **Look** | The Settings page that switches between Windows style and Mac style. |
| **Windows style** | Taskbar at the bottom, window buttons at the top right. |
| **Mac style** | Menu bar at the top, a dock at the bottom, window buttons at the top left. |
| **Dock** | The floating row of app icons at the bottom in Mac style. |
| **Task Manager** | Shows what is running and lets you close an app that has stopped responding. |
| **Terminal** | A window for typing commands. You do not need it for everyday use. |
| **Welcome** | The short tour that opens after first-time setup. |

## Words about installing and updating

| Word | What it means |
|---|---|
| **Installer** | The file you put on a USB stick to install OneClick OS on a PC. |
| **Start-up list** | The short list shown as the PC starts, for choosing which system or version to run. |
| **Dual boot** | Having Windows and OneClick OS on one PC and choosing one at start-up. |
| **Full update** | New features, fixes and security fixes. |
| **Security only** | Keeps the system as it is and installs only fixes for security problems. |
| **Undo the last update** | Goes back to the version you had before the update. |
| **Test version** | An unfinished version offered so people can try it and report problems. |

## Words about Windows programs and games

| Word | What it means |
|---|---|
| **.exe, .msi** | Windows program and installer files. |
| **Bottles** | A free app that runs many Windows programs on PCs with an Intel or AMD processor. |
| **Steam** | A games store and library. |
| **Proton** | The part of Steam that runs Windows games. |
| **Anti-cheat** | Software in online games that looks for cheating. The kind built deep into Windows blocks other systems. |
| **Cloud gaming** | The game runs on a company's computer and is shown on yours over the internet. |

## Technical names you may meet elsewhere

You do not need these to use OneClick OS. They appear in web searches and in some apps' own text.

| Name | What it is |
|---|---|
| **Linux** | The family of systems OneClick OS belongs to. Advice written "for Linux" often applies, but not always. |
| **Fedora, Bazzite** | The systems OneClick OS is built on. |
| **KDE Plasma** | The desktop OneClick OS is built on. Some windows still show its name. |
| **Flatpak, Flathub** | The format apps come in, and the collection the App Store gets them from. |
| **Dolphin, Discover, Konsole** | The original names of Files, App Store and Terminal. |
| **Distro** | Short for distribution. A complete system built on Linux. OneClick OS is one. |
