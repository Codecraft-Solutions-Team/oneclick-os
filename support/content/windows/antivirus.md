You do not need to buy or install an antivirus program on OneClick OS. None is built in, and nothing nags you to subscribe to one. That does not mean the PC is immune to everything, so it is worth knowing what protects you and what does not.

## Why it is different from Windows

- **Windows viruses are written for Windows.** They do not run on this system by themselves.
- **Apps come from the App Store.** You are not downloading setup files from websites, which is how most unwanted software arrives on Windows. See [Why you do not download installers from websites](/windows/installing-is-different).
- **The core of the system is protected.** Apps cannot change it. Changing anything system-wide asks for your password.
- **Updates replace the whole system at once**, and include security fixes. You choose when. See [How updates work](/updates/how-updates-work).

## What can still go wrong

No system stops these:

- **Fake emails and websites** that trick you into typing a password. They work the same in any browser on any system.
- **Scam phone calls and pop-ups** saying your PC is infected. They are lies. Nobody can see into your PC from a web page.
- **Windows programs run through Bottles.** A harmful Windows program can still do harm inside the space Bottles gives it. Only run Windows programs from sources you trust.
- **Commands pasted into the Terminal** from websites you do not know.
- **Weak or reused passwords.**

## Habits that matter

- Install the security fixes. Open **Settings**, choose **Update**, and check from time to time. Nothing reminds you by force.
- Keep your web browser and apps updated in the App Store.
- Use different passwords for different sites. A password manager helps.
- Type your password only when you started the action that asks for it.
- Keep a backup. See [Back up your files](/updates/back-up-your-files).

> Warning: OneClick OS is an early test version and has not had a security review. Do not rely on it to protect sensitive information.

## Files you pass on to Windows users

A file with a Windows virus in it does not affect your PC, but it can still affect a Windows PC if you forward it. Be as careful with attachments you pass on as you would be on Windows.
