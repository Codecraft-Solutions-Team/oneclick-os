---
Most things are where you expect them, often under the same name. Open the **Start menu** and start typing to find any of them.

## Everyday tools

| In Windows | In OneClick OS |
|---|---|
| Start menu | **Start menu**, bottom left. The Windows key opens it. |
| Taskbar | **Taskbar**, along the bottom |
| File Explorer | **Files** |
| Microsoft Store | **App Store** |
| Settings and Control Panel | **Settings** |
| Windows Update | **Update**, in the Start menu and in Settings |
| Task Manager | **Task Manager**. Ctrl+Shift+Esc opens it. |
| Notepad | **Text Editor** |
| Snipping Tool | **Screenshot** |
| Command Prompt, PowerShell | **Terminal**. You do not need it for everyday use. |
| System, About | **About This PC** |
| Zip folders | **Archives** |
| Disk Management | **Disks** |
| Storage, "what is using space" | **Disk Usage** |
| Phone Link | **Phone Link** |

## Apps and services

| In Windows | In OneClick OS |
|---|---|
| Microsoft Edge | Your web browser. Other browsers are in the App Store. |
| Word, Excel, PowerPoint | LibreOffice, or the **Word on the web**, **Excel on the web** and **PowerPoint on the web** shortcuts |
| OneDrive | **Settings**, then **Cloud Drives** |
| Running a .exe file | **Bottles**, set up in **Settings** under **Windows Apps** |
| Xbox app, Game Pass | The **Xbox Cloud Gaming** shortcut |
| Copilot | Nothing is built in. There are optional web shortcuts to Claude and ChatGPT. |

## Power and sign-in

At the bottom of the Start menu you find your name and four buttons: **Lock**, **Sign out**, **Restart** and **Shut down**.

## Things with no match

- **Drive letters.** There is no C drive. See [Where is the C drive](/windows/drive-letters).
- **Device Manager.** Drivers are built in. See [Where Control Panel and Device Manager went](/windows/control-panel).
- **Antivirus.** See [Do I need antivirus](/windows/antivirus).
- **A Microsoft account at sign-in.** Your account lives on the PC only.
