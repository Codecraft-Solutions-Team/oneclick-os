Windows splits its settings between Settings, Control Panel and a row of older tools. OneClick OS has one place: **Settings**.

## Open Settings

- Open the **Start menu** and choose **Settings**.
- Or open the Start menu and type what you want to change, such as "display" or "bluetooth". Settings pages appear in the results, and choosing one opens that page directly.

See [Open Settings and find a setting](/settings/open-settings).

## Where the Windows tools went

| In Windows | In OneClick OS |
|---|---|
| Control Panel | **Settings** |
| Windows Update | **Settings**, then **Update** |
| System, About | **About This PC** |
| Personalisation | **Settings**. The **Look** page switches between Windows style and Mac style. |
| Taskbar settings | **Settings**, then **Taskbar** |
| Programs and Features, Add or remove programs | **App Store** |
| Device Manager | No match. See below. |
| Task Manager | **Task Manager** |
| Disk Management | **Disks** |
| Event Viewer | **System Logs** |
| Registry Editor | No match. There is no registry. |

## Pages that OneClick adds

- **Update**: check for, download and undo system updates.
- **Look**: choose Windows style or Mac style.
- **Taskbar**: hide it, float it, move it to the top, change its size.
- **Windows Apps**: choose whether double-clicking a .exe file runs it, and set up Bottles.
- **Cloud Drives**: connect OneDrive and Google Drive.

## About Device Manager

There is no Device Manager because you do not install or update drivers yourself. Drivers are part of the system and arrive with system updates. See [Do I need to install drivers](/windows/drivers).

To see what hardware the PC has, open **About This PC**. It shows the processor, memory and graphics. See [About This PC](/settings/about-this-pc).

If a device is not working, there is no driver list to dig through. Look for the device in the troubleshooting pages, and if nothing fits, [report a problem](https://oneclickos.org/report).

## About Task Manager

Press **Ctrl+Shift+Esc**, as in Windows. It shows what is running and how busy the PC is, and lets you close an app that has stopped responding. See [Task Manager](/desktop/task-manager).
