The Word, Excel, PowerPoint and Outlook programs that you install on Windows do not run on OneClick OS. Microsoft does not make them for this kind of system. Your files are not stuck, though. There are two ways to keep working with them.

## LibreOffice

LibreOffice is a free office suite. It opens and saves Word, Excel and PowerPoint files.

- OneClick OS is set up to install LibreOffice the first time you sign in. If it is not there, install it from the **App Store**.
- Double-clicking a .docx, .xlsx or .pptx file opens it in LibreOffice.
- It works without an internet connection and needs no account.

Ordinary documents come across well. Complicated ones may look a little different: unusual fonts, heavy layouts, tracked changes, and spreadsheets with macros. If a document has to look exactly right for someone else, check it before you send it.

See [Open and edit Word, Excel and PowerPoint files](/apps/libreoffice).

## Office on the web

Microsoft offers Word, Excel and PowerPoint as websites. They are the real Microsoft apps, with fewer features than the desktop versions.

- The Start menu has **Word on the web**, **Excel on the web** and **PowerPoint on the web** shortcuts. Each opens the web version in your browser.
- You sign in with a Microsoft account. Nothing is installed.
- You need an internet connection.
- Files are kept in OneDrive.

See [Use Microsoft Office on the web](/apps/office-on-the-web).

## Which to choose

| If you | Use |
|---|---|
| Write letters, reports and simple spreadsheets | LibreOffice |
| Work offline | LibreOffice |
| Share and edit files with people who use Microsoft 365 | Office on the web |
| Need the layout to match Word exactly | Office on the web |
| Rely on Excel macros, Access or Publisher | Keep Windows for those |

You can use both. Many people write in LibreOffice and open the web version only when a file has to be exact.

## Outlook and Teams

- Outlook email works in a web browser at Microsoft's Outlook site. For an email app, see [Email and calendar](/apps/email-and-calendar).
- Microsoft Teams works in a web browser.

## Your OneDrive files

OneDrive can appear as a folder in **Files**. Set it up in **Settings** under **Cloud Drives**. See [Connect OneDrive](/apps/onedrive).
