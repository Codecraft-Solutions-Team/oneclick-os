---
Most everyday things work: browsing, video, music, photos, PDFs, email and web apps. Some things made only for Windows do not, and no setting changes that. It is better to know before you install.

## The list

| Does not work | Use instead |
|---|---|
| Online games with kernel anti-cheat | Cloud gaming, or keep Windows for those games |
| Adobe desktop apps | Other creative apps from the App Store |
| Desktop Microsoft Office | LibreOffice, or Office on the web |
| iTunes and iCloud for Windows | iCloud in a web browser |
| Some hardware, such as certain fingerprint readers | A password |
| Windows programs on PCs with an Arm processor | Nothing. Bottles needs an Intel or AMD processor. |

## Games with kernel anti-cheat

Some online games use anti-cheat that runs deep inside Windows. Their makers block every other system on purpose. Fortnite, Valorant, and recent Call of Duty and Battlefield games are examples.

- The **GeForce NOW** and **Xbox Cloud Gaming** shortcuts in the Start menu play games from the cloud, where the game runs on someone else's computer. Check each service for which games it offers.
- Keeping Windows beside OneClick OS lets you restart into Windows for those games. See [Keep Windows and install OneClick beside it](/getting-started/dual-boot-with-windows).

Many other games do run. See [Which games work and which do not](/gaming/which-games-work) and [Why some online games will not run](/gaming/anti-cheat).

## Adobe apps

Photoshop, Premiere Pro, Illustrator and the rest of Creative Cloud do not run. See [Photoshop and other Adobe apps](/windows/adobe).

## Microsoft Office

The Office programs you install on Windows do not run. Your documents still open. See [Microsoft Office](/windows/microsoft-office).

## Other Windows programs

Many Windows programs run through a free app called Bottles, on PCs with an Intel or AMD processor. Not all of them work, and there is no way to know for certain without trying. See [Run Windows programs](/apps/windows-programs).

## Hardware

Most hardware works without any setup. A few devices have no drivers for this system and cannot be made to work. See [Do I need to install drivers](/windows/drivers).

## If something you need is not on this list

That does not mean it works. Search for the program's name with the word "Linux" to see what others have found. If it fails on OneClick OS, please [report it](https://oneclickos.org/report) so this list can grow.
