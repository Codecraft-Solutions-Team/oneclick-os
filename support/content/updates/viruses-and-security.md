No computer is immune to every threat, and this page does not promise that. It explains what OneClick OS does that lowers the risk, and what is still up to you.

## What the system does

**Apps come from one place.** You install apps from the **App Store**, not by downloading installer files from websites. Fake download pages and installers with extras bundled in are one of the most common ways Windows PCs get infected, and that route is mostly closed here. See [Where apps come from and whether they are safe](/apps/where-apps-come-from).

**The system files are read-only.** The part of the disk that holds OneClick OS itself cannot be changed by an app or by a file you open. An update replaces it as a whole.

**Updates can be undone.** If an update causes a problem, the previous version is still there. See [Undo an update](/updates/undo-an-update).

**Windows viruses are written for Windows.** Most do nothing here. That is not a guarantee. A Windows program you run on purpose through Bottles behaves as it would on Windows inside its own area, so only run ones you trust.

## What is still up to you

- **Install security fixes.** Nothing updates by itself, so open **Update** and press **Check now** every week or two. See [How updates work](/updates/how-updates-work).
- **Update your apps**, especially your web browser. See [Update your apps](/apps/update-apps).
- **Watch for scams.** A fake email or website that asks for your password works on any computer. No system can stop you typing a password into the wrong page.
- **Be careful with commands.** Do not paste commands into the **Terminal** from a website or a stranger. See [The Terminal, and why you do not need it](/apps/terminal).
- **Use a good password** for your account, and lock the screen when you walk away. See [Change your password](/settings/password).
- **Keep a backup.** See [Back up your files](/updates/back-up-your-files).

## Do I need antivirus

Most people using OneClick OS at home do not install one. The longer answer is in [Do I need antivirus](/windows/antivirus).

> Note: OneClick OS is an early test version. Do not rely on it yet for work where a security failure would be serious.
