If you preferred how an older version worked, you can go back to it. Your files and apps are not affected.

This is different from **Undo the last update**:

- **Undo the last update** returns the PC to exactly what it ran before your most recent update. It needs no download. See [Undo an update](/updates/undo-an-update).
- **Previous versions** lets you choose any earlier version that has been published, by its number. It is downloaded like an update.

## Choose an earlier version

1. Open **Settings** and choose **Update**.
2. Scroll down to **Previous versions**.
3. Each version is listed as **OneClick OS** followed by its number. The one you are using now is marked **(this PC)**.
4. Beside the version you want, press **Download** or **Download and restart**.
5. Enter your password when asked.

**Download** fetches the version and uses it the next time you restart. **Download and restart** restarts as soon as it is ready. See [Download now, restart later](/updates/update-and-restart).

## What you get

The page explains it this way: each version keeps its own features and includes the latest security fixes.

So an earlier version looks and works the way it did, but it is not left with old security problems.

After you move to an earlier version, the PC stays on it. It is treated as **Security only**, so later checks offer security fixes for that version and nothing else. See [Full updates or security fixes only](/updates/full-or-security).

## Return to the newest version

1. Open **Settings** and choose **Update**.
2. Under **Updates to receive**, select **Full**.
3. Press **Check now**, then download the version that is offered.

## If the list is empty

If you see **No earlier versions have been published yet**, there is nothing older to choose. This is normal early in the test period. The list also needs an internet connection to load.

> Note: Moving to an earlier version has not been tested as widely as the rest of the Update page. If it does not work, please [report it](https://oneclickos.org/report). You can still use **Undo the last update**.
