OneClick OS lets you decide what kind of updates you receive. There are two choices, and you can change your mind at any time.

## The two choices

On the **Update** page, under **Updates to receive**, you pick one:

- **Full: new features and security fixes.** You follow the newest version of OneClick OS. Each update can bring new features, changes to how things look, fixes for bugs, and security fixes.
- **Security only: keep this version, receive security fixes.** You stay on the version you have now. It keeps the same features and the same look. The only thing you receive is that same version rebuilt with security fixes.

Under the two choices the page says: "Updates are never installed without you choosing to." That is true for both.

## Which to pick

| Pick | If |
| --- | --- |
| Full | You want improvements as they arrive. During the test period this is also how you get fixes for bugs. |
| Security only | The PC works the way you want and you do not want anything to move or change. |

> Note: OneClick OS is an early test version. Bug fixes that are not about security arrive in Full updates only. If you are waiting for a fix to a problem you reported, stay on Full.

## Change your choice

1. Open **Settings** and choose **Update**.
2. Under **Updates to receive**, select **Full** or **Security only**.
3. Press **Check now**.

The choice applies from the next check. Nothing is downloaded when you change it.

## Going from Security only back to Full

Select **Full** and press **Check now**. If a newer version exists you are offered it, and you choose whether to download it.

## Earlier versions count as Security only

If you pick an earlier version from the **Previous versions** list, the PC is set to **Security only** for that version, so it is not moved forward again at the next update. See [Go back to an earlier version](/updates/previous-versions).
