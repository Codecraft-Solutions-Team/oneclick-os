**Task Manager** shows what your PC is doing right now. Use it to find out why things feel slow, or to close an app that has frozen.

## Open it

Open the **Start** menu and choose **Task Manager**. It is pinned there to begin with. You can also type `task manager` in the Start menu search.

> Note: The welcome tour mentions pressing **Ctrl+Shift+Esc**, as in Windows. If that does nothing on your PC, open Task Manager from the Start menu instead.

## What it shows

Task Manager has several pages, listed down the side:

- An overview with how busy the processor is, how much memory is in use, and network and disk activity.
- A list of the apps you have open and how much each one is using.
- A list of every process. A process is any program that is running, including small background ones you never see as a window.
- Graphs of the last few minutes.

Click a column heading, such as the one for memory or processor use, to sort the list and bring the heaviest items to the top.

## Close an app that has frozen

1. Open **Task Manager**.
2. Go to the list of apps.
3. Select the app that is stuck.
4. Choose the option to quit or end it. You can also right-click the app for the same option.

Any work in that app that you had not saved is lost.

> Warning: In the full list of processes, only end things you recognise. Ending a part of the system can sign you out or make the screen go blank until you restart.

## When to use something else

- If the whole screen is stuck and you cannot open Task Manager, see [The screen is frozen](/troubleshooting/frozen).
- If the PC is slow all the time, see [The PC feels slow](/troubleshooting/slow).
- If the disk is filling up, see [See what is using your disk space](/settings/storage).
