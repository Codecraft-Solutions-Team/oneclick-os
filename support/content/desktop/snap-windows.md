title: Snap windows side by side
summary: Put two windows next to each other, or one in each corner.

Snapping makes a window take up exactly half or a quarter of the screen. It is the quickest way to see two things at once.

## Snap with the mouse

1. Drag a window by its title bar.
2. Keep dragging until the pointer touches the left or right edge of the screen. An outline shows where the window will go.
3. Let go. The window fills that half of the screen.

Do the same with a second window on the other side.

Other places to drag to:

- **The top edge** makes the window fill the whole screen.
- **A corner** makes the window fill that quarter of the screen.

To undo a snap, drag the window away from the edge by its title bar. It goes back to the size it was before.

## Snap with the keyboard

Hold the Windows key and press an arrow key:

| Keys | What happens |
| --- | --- |
| Windows key + Left arrow | Window fills the left half |
| Windows key + Right arrow | Window fills the right half |
| Windows key + Up arrow | Window fills the top half |
| Windows key + Down arrow | Window fills the bottom half |

To put a window in a corner, press two of these one after the other. For example, Windows key + Left arrow and then Windows key + Up arrow puts it in the top-left quarter.

## Differences from Windows

OneClick does not show a picker of other windows to fill the empty half after you snap the first one. Snap each window yourself.
