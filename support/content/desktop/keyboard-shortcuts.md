Most shortcuts you know from Windows work here too. The key with the Windows logo is called the Windows key in these articles.

## Everyday shortcuts

These work in almost every app, the same as in Windows.

| Keys | What it does |
| --- | --- |
| Ctrl+C | Copy |
| Ctrl+X | Cut |
| Ctrl+V | Paste |
| Ctrl+Z | Undo |
| Ctrl+A | Select everything |
| Ctrl+S | Save |
| Ctrl+F | Find |
| Ctrl+P | Print |
| F2 | Rename the selected file |

## Windows and apps

| Keys | What it does |
| --- | --- |
| Windows key | Open the Start menu |
| Alt+Tab | Switch between open windows |
| Alt+F4 | Close the window you are using |
| Windows key + Left arrow or Right arrow | Snap the window to that half of the screen |
| Windows key + Up arrow or Down arrow | Snap the window to the top or bottom half |
| Windows key + D | Show the desktop |
| Windows key + W | See all open windows and desktops |
| Ctrl + Windows key + Left arrow or Right arrow | Move to the next desktop |

## System

| Keys | What it does |
| --- | --- |
| Windows key + L | Lock the screen |
| Windows key + E | Open Files |
| Windows key + V | Show things you copied recently |
| Print Screen | Take a screenshot |

## In the Start menu

| Keys | What it does |
| --- | --- |
| Type anything | Search apps, settings and files |
| Enter | Open the first result |
| Down arrow | Move into the list of results |
| Esc | Close the menu |

## If a shortcut does not work

This is an early test version, and a few shortcuts may differ on some keyboards. To see or change shortcuts, open **Settings** and search for `shortcuts`.

If the Windows key does not open the Start menu, please [report it](https://oneclickos.org/report).
