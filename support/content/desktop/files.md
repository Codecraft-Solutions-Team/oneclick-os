**Files** is where you browse your folders. It does the job that File Explorer does in Windows.

## Open Files

Click the folder icon on the taskbar, or open the **Start** menu and choose **Files**.

## Where your things are

Files opens in your **Home** folder. Everything that belongs to you lives inside it, in folders with familiar names such as **Documents**, **Downloads**, **Pictures**, **Music** and **Videos**. These are also listed down the left side of the window so you can jump to them.

There is no C drive. Your Home folder takes its place for everyday use. See [Where is the C drive](/windows/drive-letters).

## Everyday jobs

- **Open** a file or folder by double-clicking it. A single click selects it.
- **Go back** with the back arrow at the top, as in a web browser.
- **Copy or move** by dragging, or use **Ctrl+C**, **Ctrl+X** and **Ctrl+V** as in Windows.
- **Rename** by selecting the file and pressing **F2**.
- **Make a new folder** by right-clicking an empty area and choosing the option to create a folder.
- **Delete** by selecting the file and pressing **Delete**. It goes to the **Trash**, which works like the Recycle Bin. Open Trash from the left side of the window to put a file back or to empty it.
- **Select several files** by holding **Ctrl** and clicking each one, or by dragging a box around them.

Right-click any file to see everything you can do with it.

## Search in a folder

Press **Ctrl+F** in Files to search inside the folder you are in. To search from anywhere, type in the Start menu. See [Search for apps, files and settings](/desktop/search).

## Other places

- USB sticks and external drives appear on the left side when you plug them in. See [USB sticks and external drives](/desktop/external-drives).
- OneDrive and Google Drive can appear in Files once you connect them. See [The Cloud Drives page](/settings/cloud-drives-page).
- To pick which app opens a kind of file, see [Choose which app opens a file](/apps/default-apps).
